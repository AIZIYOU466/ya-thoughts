═══════════════════════
背景
═══════════════════════
用户希望所有删除操作（手动删除 + 自动清理）都进"回收箱"，
回收箱保留 3 天，超期永久删除。用户可随时恢复或彻底删除。

═══════════════════════
一、数据结构改动
═══════════════════════
note 对象新增两个字段（不破坏旧数据，读取时默认补齐）：

1. deletedAt：数字时间戳或 null。null = 未删除。
2. deletedFrom：字符串 'manual' | 'auto' | null。标记删除来源。

DB_VERSION 保持 3（不升级，因为只是新增可选字段，读取时补齐）。

═══════════════════════
二、删除流程改造（所有入口统一进回收箱）
═══════════════════════
以下所有删除操作改为"标记删除"而不是物理删除：

1. 左滑删除（removeNoteNow 或等价函数）：
   - 设置 note.deletedAt = Date.now()、deletedFrom = 'manual'
   - 写回 IndexedDB
   - 卡片从列表移除（不重建全表，只移除这一张）

2. 编辑页右上角删除按钮：
   - 同上

3. 多选批量删除（#sel-delete）：
   - 同上，逐个标记

4. 自动清理（见下文）：
   - 设置 deletedAt + deletedFrom = 'auto'

所有物理删除（dbDelete 调用）改为标记删除。图片 Blob 暂不删除，
等回收箱超期时才清理关联图片。

═══════════════════════
三、列表查询过滤
═══════════════════════
所有列表渲染（renderList、sortedNotesFor 等）：
- 只显示 deletedAt 为 null 或 undefined 的便签。

回收箱查询：
- 只显示 deletedAt 非空的便签。

═══════════════════════
四、回收箱 UI
═══════════════════════
入口：⋯ 菜单 → "回收箱"（放在"检查更新"和"关于"之间）。

回收箱页面（独立视图，或全屏 overlay）：
- 标题栏：左"←"返回，中"回收箱"，右"清空"按钮（红色文字）。
- 列表：每条显示：
  · 便签标题（或"无标题"）
  · 小字："手动删除于 X 前" 或 "自动清理于 X 前"
  · 小字："还剩 X 天"（3 天倒计时，超期自动消失）
- 每条右侧有"恢复"按钮（主色文字）。
- 点击条目本身或"恢复" → 恢复便签：
  · deletedAt = null，deletedFrom = null
  · 回到列表页的原始位置（按 updatedAt 排序）
- 点"清空" → confirmDialog 确认 → 永久删除所有回收箱条目。
- 空态："回收箱是空的"

═══════════════════════
五、自动清理
═══════════════════════
设置里加"自动清理"选项（已在之前任务里规划，这里合并）：

两个开关：
- "自动清理已完成事项"（默认关闭）
- "自动清理已过期事项"（默认关闭）
- 状态存 localStorage：auto_clean_done / auto_clean_expired

执行时机：App 启动时检查（不用后台定时任务）。
执行条件：
- 今天 20:00 已过（本地时间）
- 今天还没清理过（localStorage 记 auto_clean_last_date，格式 YYYY-MM-DD）

执行逻辑：
1. 找出所有符合条件的便签（未删除、符合清理条件）。
2. 逐个设 deletedAt = Date.now()、deletedFrom = 'auto'。
3. 如果有清理，弹窗提示：
   "已自动清理 X 条事项"
   下面列出具体条目（最多 10 条）：
   "· 已完成：标题1"
   "· 已过期：标题2"
   底部："可在回收箱找回（保留 3 天）"
   按钮："知道了"

═══════════════════════
六、回收箱超期清理
═══════════════════════
App 启动时（和自动清理一起）执行：
- 找出所有 deletedAt + 3*24*60*60*1000 < now 的便签
- 物理删除（dbDelete + 删除关联图片 Blob）
- 静默执行，不提示（超期是正常回收）

═══════════════════════
严格约束
═══════════════════════
- 分步实现：先做数据结构 + 删除改造 + 列表过滤（不破坏现有功能），
  再做回收箱 UI，最后做自动清理。
- 不动图片裁剪、更新弹窗、通知。
- 每步做完报告，用户测试通过后再做下一步。
- 纯原生 JS，不改 DB_VERSION。
- 所有时间计算用本地时区。
