# 任务：回收箱返回键 + 自动清理时机 + 待办进行中状态

技能加载：systematic-debugging、ponytail、ui-ux-pro-max-skill。
先输出方案报告，等确认后再动手。

## 问题 1：回收箱页面的系统返回键
现象：在回收箱页面，用手机系统侧边手势返回 → 直接退到桌面。
     点击左上角小箭头 → 正常返回列表页。
根因方向：Capacitor 的 backButton 监听器没有处理"回收箱打开"的情况。
修复：
- 在 backButton 监听器里加判断：如果回收箱打开，先关闭回收箱，return。
- 判断顺序参考现有的"更新弹窗 / 查看器 / 裁剪 overlay / 多选"。

## 问题 2：自动清理时机
现状：设置里文案是"每天 20:00 自动执行"。
用户预期：App 启动时检查执行（每天一次）。
修复：
- 文案改为"每次打开 App 时检查并清理（每天一次）"
- 逻辑：App 启动时检查，如果今天还没清理过，就执行一次。
- localStorage 记 auto_clean_last_date = YYYY-MM-DD
- 去掉"20:00"判断。

## 问题 3：待办"进行中"状态没有视觉标记
现状：已完成有绿圈、已过期有红圈 + 红字。
     "进行中"没有任何视觉标记。
用户预期："进行中"也要有视觉提示。
修复建议（三选一，先输出推荐+理由）：
A. 空心白圈 + 无额外标记（默认样式）
B. 右上角小字标签"进行中"（灰色或主色）
C. 卡片左侧加细的蓝色竖线（2px 宽）
