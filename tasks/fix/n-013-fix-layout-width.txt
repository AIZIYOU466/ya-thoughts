现象描述
═══════════════════════════════════════

用户截图显示（真机 APK v1.5.0）：

【主界面】
- 顶栏"便签"标题被裁切，右侧有大量空白。
- 搜索框、分段控件、卡片都没有撑满屏幕宽度。
- 整个列表页内容似乎被压窄到屏幕左侧 60% 左右，右侧 40% 空白。

【编辑页】
- 左侧玻璃面板只占屏幕约一半宽度。
- 右侧大片空白。
- 顶栏按钮（返回/撤销/重做/分享/删除）挤在屏幕左侧一小块区域。

【编辑页滚动】
- 下滑时底部出现空白，内容区域没有撑满。

共同现象：所有页面内容都没有撑满视口宽度，右侧有持续空白。

═══════════════════════════════════════
根因排查（systematic-debugging 流程）
═══════════════════════════════════════

按以下顺序检查：

1. 检查 <html> 和 <body> 的宽度约束：
   a. body 是否有 max-width？
   b. body 或 html 是否有 width: 100%？
   c. body 是否有 margin-left/right 非零值？
   d. body 是否有 padding-left/right 过大？
   e. body 是否开启了 display: flex 但没有 justify-content: center？
   f. box-sizing 是否统一为 border-box？

2. 检查根容器（#app 或类似）：
   a. 是否设置了固定宽度（比如 width: 60%）？
   b. 是否有 transform: scale 或 translate 影响？
   c. 是否在液态玻璃重做时被包进了一个新容器，而新容器宽度算错？

3. 检查 #list-view 和 #editor-view：
   a. #list-view 原来应该是 position: fixed; inset: 0。现在是什么？
   b. #editor-view 原来应该是 position: fixed; inset: 0。现在是什么？
   c. 是否被改成 position: relative 但忘了 width: 100%？

4. 检查液态玻璃引入的新容器：
   a. .editor-panel 是什么定位？宽度多少？
   b. .editor-panel 是否引入了额外的 margin 或 padding 把宽度压缩？
   c. 是否有元素用了 backdrop-filter 但引入了意外的尺寸计算？

5. 检查 viewport meta 标签：
   a. 是否是 <meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">？
   b. 是否被改动过（比如加上了 maximum-scale 或 width=xxx）？

6. 检查是否有元素超出视口宽度导致横向滚动：
   a. 搜索 overflow-x: hidden 或 max-width: 100vw 的使用。
   b. 是否有元素宽度计算包含了 padding/border（box-sizing 问题）？

═══════════════════════════════════════
修复方向
═══════════════════════════════════════

根据排查结果针对性修复。大概率是以下之一：

【可能 1：body/html 宽度约束】
- 确保 html, body { width: 100%; margin: 0; padding: 0; box-sizing: border-box; }
- 确保 #app / #list-view / #editor-view 都是 width: 100% 或 position: fixed; inset: 0。

【可能 2：液态玻璃新容器引入宽度问题】
- 检查 .editor-panel 的定位和尺寸。它应该是包裹在 #editor-view 内部的一个容器：
  · 宽度：calc(100% - 24px)（左右各留 12px 边距）
  · 高度：calc(100% - 顶部栏高度 - 底部工具栏高度)
  · margin: auto 居中，或者用 flex 布局
- 如果 .editor-panel 引入了 width: 60% 之类的问题，改成自适应。

【可能 3：#list-view / #editor-view 定位被改错】
- 这两个容器都应该是 position: fixed; top: 0; left: 0; right: 0; bottom: 0;
- 如果 #editor-view 被改成 position: relative，需要补 width: 100%; height: 100vh。

【可能 4：viewport meta 被改动】
- 检查 head 里的 viewport meta，恢复为标准配置。

═══════════════════════════════════════
严格约束
═══════════════════════════════════════

- 只修布局宽度问题，不改功能逻辑。
- 纯原生 CSS 修复，尽量不动 JS。
- 保留液态玻璃的视觉风格（只是修复尺寸问题，不改颜色、圆角、阴影）。
- 不改：自动保存、图片、撤销/重做、多选、导出/导入、待办、提醒、搜索、置顶、排序、分享、摘要展开、删除动画、toast、confirmDialog、左滑菜单、底部胶囊、卡片时间。
