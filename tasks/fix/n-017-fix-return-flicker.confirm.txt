问题 1：返回时闪蓝底（同意，但要加保险）
═══════════════════════════════════════

同意你的方案：hideEditorWithTransition() 里提前让列表页可见。

但要加两条保险，避免副作用：

1. **确认层叠关系**：
   - 检查 #list-view 和 #editor-view 的 z-index。
   - 编辑页必须严格在列表页之上（z-index 更高）。
   - 如果列表页提前 visible 后，编辑页滑出动画期间能透过它看到列表内容，说明层叠正确。
   - 如果编辑页被列表页盖住，说明 z-index 反了，需要调整。

2. **列表页提前可见时，不要重建 DOM**：
   - listView.classList.add('active') 只改 visibility，不触发 renderList。
   - 如果这个类切换会触发 resize observer 或 media query 重算，注意性能。

执行细节：
- hideEditorWithTransition() 开头就 listView.classList.add('active')。
- 编辑页 .leaving 添加后，两页同时存在（列表页在下，编辑页在上滑出）。
- finishEditorAnim() 里移除 listView 的重复 add（幂等，不影响）。
- show('editor') 进入编辑页时，listView 保持 active（不要移除），编辑页盖住它即可。
