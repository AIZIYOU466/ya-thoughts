═══════════════════════════════════════
问题描述
═══════════════════════════════════════

现象（真机 APK 和浏览器都出现）：
- 从列表页进入编辑页时，编辑页从右侧滑入。
- 编辑页滑入的过程中，能看到底部列表页的文字（透过编辑页看到）。
- 直到编辑页完全打开，列表页才被"覆盖"掉。
- 用户观感：编辑页滑入时"半透明"，遮挡不彻底。

用户期望：
- 编辑页从右侧滑入时，应该**完全不透明**地遮住底下的列表页。
- 滑入过程中，看不到任何列表页的文字。
- 编辑页内部保留液态玻璃效果（顶栏、工具栏、面板的玻璃质感不变）。
- 只保留"编辑页从右侧滑入"这一个转场动画，不需要"列表页被推开"的效果。

═══════════════════════════════════════
根因分析
═══════════════════════════════════════

排查：
1. 检查 #editor-view 的 background 属性：
   - 是不是 transparent？
   - 是不是半透明色（rgba 带透明度）？
   - 是不是完全没有 background（默认透明）？
2. 检查 #editor-view 的 HTML 结构：
   - 它包含哪些子元素？
   - .editor-panel 是不是一个半透明的玻璃面板？
   - 面板的 backdrop-filter 是不是把底下的列表页也模糊了？
3. 检查 body 的背景实现：
   - body 有渐变 + 光斑 + SVG 噪点。
   - 编辑页透明时，这些背景会透出来，列表页也会透出来。
4. 检查 .no-blur 类的逻辑：
   - 它是否在编辑页滑入期间关闭了玻璃元素的模糊？
   - 如果关闭，玻璃面板变成半透明背景，用户就能透过看到列表页。

预期根因：
- #editor-view 本身透明，列表页透出来。
- .editor-panel 是半透明玻璃面板，滑入过程中未完全遮住列表页。

═══════════════════════════════════════
修复方案
═══════════════════════════════════════

核心思路：**给 #editor-view 加一层不透明底板**，让编辑页滑入时完全遮住列表页。

具体：

1. **给 #editor-view 添加不透明背景**：
   - 用 body 背景的等效色值，比如线性渐变：
     linear-gradient(180deg, #EAF2FB 0%, #D8E8F5 100%)
   - 或者直接用最接近 body 背景的纯色：#EEF4FB
   - 不要用 var(--bg-page) 如果它本身是透明的或半透明的——先确认。

2. **或者用伪元素做底板**：
   #editor-view::before {
     content: '';
     position: absolute;
     inset: 0;
     background: linear-gradient(180deg, #EAF2FB, #D8E8F5);
     z-index: 0;
     pointer-events: none;
   }
   #editor-view > * {
     position: relative;
     z-index: 1;
   }
   （确保子元素在底板之上）

3. **保留编辑页内部的玻璃效果**：
   - .editor-panel 的 backdrop-filter 不改。
   - 但玻璃面板现在的"模糊对象"变成了编辑页的不透明底板，而不是列表页。
   - 视觉上：玻璃面板依然模糊，但模糊的对象是编辑页自己的背景色，效果依然柔和。

4. **检查 .no-blur 的影响**：
   - 如果 .no-blur 在滑入期间关闭了编辑页内的 backdrop-filter，
     .editor-panel 会变成半透明背景，透过它看到列表页。
   - 修复：.no-blur 只针对列表页的元素（#list-view 内的），
     不要波及 #editor-view 内的玻璃元素。
   - 具体检查 .no-blur 的 CSS 规则，看它是否命中了 .editor-panel / .editor-bar / .editor-toolbar。
   - 如果命中，从 .no-blur 的规则里移除这些选择器。

5. **验证 z-index 层叠**：
   - #list-view z-index 应该低于 #editor-view。
   - #editor-view 的不透明底板应该盖住 #list-view。
   - #editor-view 内的子元素（顶栏、面板、工具栏）在底板之上。
