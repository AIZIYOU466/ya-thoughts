# 任务：通知加声音 + 顶部弹出（heads-up）

技能：systematic-debugging、ponytail。
先输出方案报告，等确认后再动手。

## 现状
通知框架已搭好（7 个函数：checkDueReminders / getLocalNotifications /
requestNotificationPermission / cancelNoteNotification /
scheduleNoteNotification / resyncAllTodoNotifications /
registerNotificationTap），但缺三样：
1. 没有创建通知渠道（createChannel / channelId / importance 都搜不到）
2. 没有设置声音（sound 搜不到）
3. 没有高优先级（不触发 heads-up 顶部弹出）

## 目标
1. 通知到达时播放系统默认铃声
2. 通知在屏幕顶部弹出（heads-up），而不是只在通知栏静默出现
3. 通知样式对齐 App UI（图标、颜色）

## 具体实现

### 1. 创建通知渠道（关键）
Android 8+ 必须通过渠道控制 heads-up。在 Capacitor 就绪后调用一次：

await LocalNotifications.createChannel({
  id: 'todo-reminders',
  name: '待办提醒',
  description: '待办事项到时提醒',
  importance: 5,        // 5 = HIGH，必须，才触发顶部弹出
  visibility: 1,        // 1 = PUBLIC，锁屏可见
  vibration: true,
  sound: 'default',     // 系统默认铃声
  lights: true,
  lightColor: '#2E6BE6' // App 主色
});

放在哪个函数里：找一个"App 启动时执行一次"的位置（比如和 requestNotificationPermission 一起）。

### 2. scheduleNoteNotification 补充字段
在 LocalNotifications.schedule 的通知对象里加：

{
  ...
  channelId: 'todo-reminders',  // 指向上面创建的渠道
  sound: 'default',              // 播放系统默认铃声（有些版本要和 channel 一起设）
  smallIcon: 'ic_stat_icon',     // 如果有通知小图标就用，没有就用默认
  iconColor: '#2E6BE6',          // App 主色
  ongoing: false,
  autoCancel: true
}

### 3. 检查是否已请求通知权限
requestNotificationPermission 已有，确认它在 App 启动时被调用。

### 4. 小图标（可选）
如果 android/app/src/main/res/drawable/ 下有 ic_stat_icon 之类的小图标，就引用它。
没有的话，用 ic_launcher 代替，或者先不设 smallIcon 用默认。
