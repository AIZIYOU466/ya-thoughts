═══════════════════════════════════════
任务 2：修复编辑页返回列表页的闪动
═══════════════════════════════════════

用户现象：
- 编辑页点左上角 "<" 返回箭头 → 列表页整页闪动，像重加载。
- 手机系统手势返回 → 不闪。

要求（systematic-debugging 流程）：
1. 找到返回箭头的 click 处理函数和系统返回的处理函数。
2. 对比两者：是否调用同一个 backToList()？
3. 深入 backToList()：
   a. 是否调用了 renderList()？如果是，renderList 做了什么？
   b. 是否重建了 DOM（innerHTML = '' 之类）？
   c. 是否重置了滚动位置？
   d. 是否重建了 FAB（右下角 + 按钮）？
4. 检查编辑页关闭时的动画和 blur 事件是否触发额外操作。

修复方向：
- 让返回箭头和系统手势走**完全相同的路径**。
- backToList 不做任何 DOM 重建，只：
  · 编辑页移除 active
  · 列表页恢复可见
  · 如果编辑器有未保存内容，只更新对应卡片的文本，不重建整个列表
- 滚动位置保留（不重置 scrollTop）。
- FAB 不重建。

任务 3：全局液态玻璃质感主题
═══════════════════════════════════════

参考 iOS 26 的 Liquid Glass 风格。核心是：模糊、磨砂、通透、有立体感。

【全局背景】
- body 背景用一个柔和、模糊的渐变作为"底"，可以带一点点噪点纹理（用 SVG filter 生成，不要外部图片）。
- 渐变色调：以浅蓝为主，例如从 #EAF2FB 到 #D8E8F5。
- 背景加一层非常淡的模糊光斑（用 CSS radial-gradient 模拟，不要外部图片）。

【玻璃卡片规则】
所有"浮在上面"的元素（卡片、顶栏、底部胶囊、弹层、菜单、确认框）用同一套玻璃质感：
- 背景：rgba(255, 255, 255, 0.55)
- backdrop-filter: blur(24px) saturate(180%)
- -webkit-backdrop-filter: blur(24px) saturate(180%)
- 边框：1px solid rgba(255, 255, 255, 0.6)
- 圆角：16px（卡片）、20px（弹层）、999px（胶囊）
- 外阴影：0 8px 32px rgba(31, 71, 136, 0.08)
- 内高光：inset 0 1px 0 rgba(255, 255, 255, 0.7)

【具体元素】
- 顶栏（#list-header）：玻璃感，底部 1px 分割线用 rgba(255,255,255,0.4)。
- 卡片（.note-item）：玻璃卡片。卡片内的文字保持清晰对比度。
- 底部胶囊（见任务 4）：玻璃胶囊。
- 多选顶栏（#sel-bar）：玻璃。
- ⋯ 菜单、confirm 确认框、toast：全部玻璃。
- 搜索框：玻璃，输入框内部比容器稍浅一点。
- 分段控件（全部/待办/已完成）：玻璃底 + 选中项实心蓝或深色。
- 图片查看器遮罩：保持深色 rgba(0,0,0,0.85)，不要玻璃化（图片需要清晰）。

【深色模式兼容】
- prefers-color-scheme: dark 时：
  · 玻璃背景：rgba(30, 34, 42, 0.55)
  · 边框：rgba(255, 255, 255, 0.1)
  · 文字用浅色 #E8EAED
- 所有 CSS 变量按深浅模式两套值。

【性能注意】
- backdrop-filter 在 Android WebView 上可能有性能开销。如果列表超过 50 条，只对"可见区域"的卡片应用 backdrop-filter（用 IntersectionObserver），滚出屏幕的去掉。

【样式】

任务 5：卡片时间显示（创建于 / 最近编辑）
═══════════════════════════════════════

【位置】
- 卡片右下角（原来是单个时间戳），改成两行小字：
  · 第一行："创建于 X"（相对时间，如"3 天前"）
  · 第二行："编辑于 Y"（相对时间，如"刚刚"）
- 字号 11px，颜色 #8A8F99（浅色）/ #9AA0A6（深色）。
- 行间距 2px，右对齐。

【相对时间格式】
- < 1 分钟：刚刚
- < 1 小时：X 分钟前
- < 24 小时：X 小时前
- < 7 天：X 天前
- < 30 天：X 周前
- < 365 天：X 个月前
- ≥ 365 天：X 年前

【规则】
- 如果 createdAt 和 updatedAt 相差 < 1 分钟（刚创建没编辑），只显示一行"创建于 X"，不显示编辑时间。
- 如果 updatedAt 就是刚刚（< 1 分钟），显示"编辑于 刚刚"。
- 用 created 字段和 updated 字段计算，不要重新生成。

【和待办的兼容】
- 待办卡片（type=todo）也要显示这两行时间，位置一致。
