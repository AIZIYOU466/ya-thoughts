给 /root/workspace/notes-app/index.html 加"左滑操作菜单"和"拖拽排序"两个手势交互。

═══════════════════════════════════════
一、左滑操作菜单
═══════════════════════════════════════

【交互】
- 用户在卡片上向左滑动超过 40px 时，卡片向左平移，右侧露出三个操作按钮：
  · 置顶（图钉图标）
  · 复制（复制图标）
  · 删除（垃圾桶图标，红色）
- 滑动过程中卡片跟手。
- 松手时：如果滑过 80px，吸附到完全展开（露出 120px）；否则弹回原状。
- 同一时间只能有一张卡片处于展开状态。点其他卡片或空白处，展开的卡片弹回。
- 点击按钮时，卡片先弹回原位，再执行对应操作。

【按钮功能】
- 置顶：切换当前便签的 pinnedAt 字段（和现有的置顶逻辑保持一致）。
- 复制：把便签的标题和正文纯文本复制到剪贴板，toast 提示"已复制"。
- 删除：调用现有的曲线删除动画，然后从 IndexedDB 删除。

【移除旧的长按菜单】
- 现在长按卡片会弹出菜单（置顶/复制/删除）。这三个操作已经移到左滑里，**把长按菜单整个去掉**。
- 长按改成什么也不做，或者只触发拖拽排序（见第二部分）。

═══════════════════════════════════════
二、拖拽排序
═══════════════════════════════════════

【交互】
- 长按卡片 500ms 后，卡片略微放大（scale 1.02）、加阴影，并跟随手指上下移动。
- 其他卡片平滑上下移动，为拖拽的卡片让出空位。
- 松手后，卡片"落"到新位置，更新排序。
- 如果长按期间手指移动不超过 10px，取消拖拽，视为普通点击（打开便签）。
- 拖拽过程中不能触发左滑菜单。
- 排序结果写入 IndexedDB（给每条 note 加一个 order 字段，初始按 createdAt 排）。

【排序和现有的排序方式的兼容】
- 现在列表有三种排序：按修改时间、按创建时间、按标题。
- 如果用户当前是"按修改时间"或"按创建时间"排序，拖拽后自动切换到"自定义排序"（新加一个排序选项），并保存拖拽后的顺序。
- 如果用户当前是"按标题"排序，禁止拖拽，长按卡片不触发拖拽。

═══════════════════════════════════════
三、手势冲突处理
═══════════════════════════════════════

- 卡片上触摸时，先判定是"横向滑动"还是"纵向滑动"：
  · 横向移动距离 > 纵向移动距离，走左滑逻辑
  · 纵向移动距离 > 横向移动距离，走滚动逻辑
- 卡片 CSS 加 touch-action: pan-y，允许纵向滚动但不允许横向滑动被浏览器接管。
- 左滑判定阈值：横向移动 > 10px 且 > 纵向移动的 1.5 倍。

═══════════════════════════════════════
四、严格约束
═══════════════════════════════════════

- 只加这两组功能，不要动其他（自动保存、图片、撤销/重做、导出/导入、待办、搜索、置顶逻辑、字数、排序、分享、主题切换、摘要展开）。
- 纯原生 JS，无依赖，不引 GSAP 或 Framer Motion。
- 用 Pointer Events（pointerdown/pointermove/pointerup）实现手势，兼容触摸和鼠标。
- CSS 用 transform: translate3d 驱动，只改 transform 和 opacity。
- 排序字段 order 加进 IndexedDB，导出/导入 JSON 时要包含。
- 改完告诉我文件大小、新增的函数名、验证结果。
