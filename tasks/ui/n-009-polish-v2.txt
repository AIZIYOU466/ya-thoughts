问题 1：拖拽排序的连锁让位不够灵敏
═══════════════════════════════════════

当前问题：
- 拖动卡片 1 到卡片 2 的位置时，2 反应迟钝，或者根本没让位
- 拖动卡片 1 到卡片 3 的位置时，2 和 3 应该依次上移一格，但实际没有
- 松手放置后，有一个多余的"快速移动动画"闪过，看起来像重复了一遍动作

正确行为（关键）：
1. 拖动卡片 A 的过程中，实时计算 A 的中心点 y 坐标，对应列表中的哪个索引位置。
2. 令 currentIndex 为 A 拖动前的原始索引，hoverIndex 为当前光标对应的目标索引。
3. 如果 hoverIndex > currentIndex：
   - 所有索引在 (currentIndex, hoverIndex] 之间的卡片，上移一格（translateY 负一个卡片高度 + 间距）
4. 如果 hoverIndex < currentIndex：
   - 所有索引在 [hoverIndex, currentIndex) 之间的卡片，下移一格
5. 让位动画：200ms ease-out，用 transform: translate3d 驱动。
6. 只有 hoverIndex 变化时才重算，避免每帧都重排。

松手放置：
- 立即更新 DOM 顺序（appendChild 调整节点位置），同时清除所有卡片的 translateY。
- 清掉 A 的 fixed 定位和 transform，让它直接落在新位置上。
- 关键：**放置后不能有任何多余的动画**。用户松手后，卡片应该"啪"地落位，其他卡片已经在正确位置，不闪、不重播。
- 如果 FLIP 动画会导致视觉重播，就完全跳过 FLIP，直接切换 DOM 顺序。

灵敏度和阈值：
- 卡片中心点进入另一个卡片的中心线 ± 20px 范围时，立即触发让位。
- 用 requestAnimationFrame 节流，不要每个 touchmove 都重排。

问题 2：主题切换的月亮图标显示不完整
═══════════════════════════════════════

当前问题：浅色模式下，按钮显示为一个半圆（残缺的月亮）。

根因：SVG path 可能写得不对，或者 viewBox 尺寸和 path 坐标不匹配。

修复：
- 打开 index.html，找到主题切换按钮的 SVG。
- 用一个标准、完整的月亮图标 path 替换。推荐这个（crescent moon 标准形状）：
  <svg viewBox="0 0 24 24" width="20" height="20" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
    <path d="M21 12.79A9 9 0 1 1 11.21 3 7 7 0 0 0 21 12.79z"/>
  </svg>
- 太阳图标用标准圆形 + 8 条光线：
  <svg viewBox="0 0 24 24" width="20" height="20" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
    <circle cx="12" cy="12" r="4"/>
    <path d="M12 2v2M12 20v2M4.93 4.93l1.41 1.41M17.66 17.66l1.41 1.41M2 12h2M20 12h2M6.34 17.66l-1.41 1.41M19.07 4.93l-1.41 1.41"/>
  </svg>
- 图标颜色继承按钮文字色（用 currentColor）。

问题 3：顶栏按钮重组
═══════════════════════════════════════

当前问题：
- "选择"是文字按钮，不够简洁。
- 右上角有一个独立的垃圾桶图标，功能和多选里的删除重叠。
- 多选模式里没有"全选"。

重组后：
【列表页顶栏】（从左到右）
- "便签"标题（居中）
- 右侧：主题切换（月亮/太阳）| 选择图标 | ⋯（三点菜单）

【"选择"按钮改成图标】
- 用一个标准的多选图标（复选框样式），例如：
  <svg viewBox="0 0 24 24" width="20" height="20" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
    <rect x="3" y="5" width="4" height="4" rx="1"/>
    <path d="M10 7h11"/>
    <rect x="3" y="15" width="4" height="4" rx="1"/>
    <path d="M10 17h11"/>
  </svg>
- 点击后进入多选模式。

【删除右上角的独立垃圾桶图标】
- 移除它在顶栏的 HTML 和事件绑定。
- 但曲线删除动画的终点锚点仍是右上角，改为使用"选择"图标的位置作为终点。

【多选模式顶栏】
- 左："取消"
- 中："已选 X 条"
- 右："全选" + "删除" + "导出"（三个按钮，间距 8px）

【"全选"逻辑】
- 点击"全选" → 选中当前分段（全部/待办/已完成）下、当前搜索过滤后的所有可见便签。
- 再次点击"全选" → 取消全选。
- 全选后，中间文字显示"已选 X 条"。
- 全选按钮文字切换：未全选时显示"全选"，已全选时显示"取消全选"。

【保留 ⋯ 菜单】
- 菜单内容不变：导出、导入、排序、关于。
- 不要把它融进多选。

问题 4：整体按钮的齐整间距和高级轻柔交互
═══════════════════════════════════════

参照 motion-web 技能的"handfeel"和"easing"规范。

【顶栏按钮】
- 所有顶栏图标按钮统一 44×44px 点击区，图标 20×20px，图标居中。
- 按钮之间的间距统一 4px（紧凑），按钮内部 padding 统一 10px。
- 顶栏右侧按钮组的整体高度与标题对齐。
- 深色/浅色模式下图标颜色一致：未激活 #1A1D21 / #E8EAED，激活 #2E6BE6。

【按钮点击反馈】
- 所有图标按钮点击时：scale(0.92) + background 变为 rgba(0,0,0,0.04)（浅色）/ rgba(255,255,255,0.06)（深色），150ms ease-out。
- 松开后恢复。

【多选模式顶栏】
- 左"取消"：文字按钮，主色 #2E6BE6，15px/500。
- 中"已选 X 条"：14px，#8A8F99。
- 右三个按钮：字号 14px/500，"全选"用灰色 #6B7280，"删除"用红色 #E5484D，"导出"用主色 #2E6BE6。
- 右侧三个按钮用 flex gap: 12px 排列，右对齐。
