为 Ya thoughts 备忘录 App 生成一个纯文字风格的 App 图标，输出 SVG 格式。

═══════════════════════════════════════
核心概念
═══════════════════════════════════════

图标只包含两个字母：大写 Y 和小写 a，紧凑排列，居中。
字母是主角，背景是淡蓝色的大海与水波纹。
整体柔和、清新、通透，不能有厚重感或复杂装饰。

═══════════════════════════════════════
画布与背景
═══════════════════════════════════════

- 512x512 viewBox
- 圆角方形背景，圆角半径 115（约 22.5%，接近 iOS 风格）
- 背景用垂直线性渐变：
  · 顶部 #DCEEFF（极浅天蓝）
  · 中部 #B8DCF5（浅海蓝）
  · 底部 #A0CFEE（稍深的海水蓝）
- 渐变方向从上到下，模拟从天空到海水的过渡

═══════════════════════════════════════
水波纹（背景装饰）
═══════════════════════════════════════

- 至少 6-8 条横向波浪线，纵向分布在整个画布（从上部到下部都有）
- 每条波浪线是一条 SVG path，用三次贝塞尔曲线画成柔和的 S 形波动
- 波浪线的宽度、振幅、位置各不相同，不要对称或规则排列
- 颜色规则（关键）：
  · 每条波浪线本身可以有颜色渐变（linearGradient），从白色渐变到淡蓝色
  · 用三种颜色交叉：纯白 #FFFFFF、浅蓝 #A8D4F0、中蓝 #7BB8E0
  · 白色部分要"通透"，像水面上反光；蓝色部分要柔和，不能太深
- 透明度和粗细：
  · 线条粗细 2-4px，圆角端点（stroke-linecap: round）
  · 白色部分透明度 0.5-0.7，蓝色部分透明度 0.4-0.6
- 关键：波浪线的形状要像"手写笔迹的流动感"，不要像机械的正弦波
  · 每条波浪线的起笔和收笔可以稍细，中段稍粗（用 path 的粗细变化模拟笔迹）
  · 波峰和波谷的弧度要自然，不要完全对称

═══════════════════════════════════════
字母 Y（主角）
═══════════════════════════════════════

- 颜色：纯白色 #FFFFFF
- 效果：要有"通透感"——不是纯实心白，而是带一点点渐变或微透明
  · 用线性渐变：从 #FFFFFF（顶部）到 #F0F8FF（底部），营造通透感
  · 或者：白色主体 + 极淡的蓝色内阴影（用 SVG filter 模拟），但不要过度
- 字体风格：圆润的无衬线字体，笔画粗细适中，端点圆角
- 用 SVG path 手绘字母，不要用 <text> 标签（避免依赖系统字体）
- Y 的形状：上方两条斜线向下汇聚成竖线，交汇点圆滑过渡
- 笔画粗细：约 56-64px（在 512 画布上）
- 位置：居中偏左，与 a 紧凑排列

═══════════════════════════════════════
字母 a（主角）
═══════════════════════════════════════

- 颜色：清新柔和的淡黄色 #FFD966
- 效果：柔和、不发亮，可以加一点从 #FFE599（顶部）到 #FFC93D（底部）的垂直渐变
- 字体风格：和 Y 一致的无衬线字体，圆润，笔画粗细相同
- a 的形状：小写 a 的标准双圆结构——一个封闭的圆 + 右侧一条短竖线
  · 圆的直径和 Y 的笔画粗细匹配
  · 竖线从圆右上方向下延伸，末尾圆角
- 位置：紧贴 Y 的右侧，间距不超过笔画宽度的 1 倍

═══════════════════════════════════════
构图与比例
═══════════════════════════════════════

- Y 和 a 的整体宽度占画布约 55-60%
- 两个字母居中对齐，垂直方向也在画布中央偏上位置（不要贴底）
- Y 的底端和 a 的底端对齐（视觉基线一致）
- 两个字母加起来形成"Ya"作为一个整体的字形
- 字母不要被水波纹遮挡（水波纹在字母下方，或者字母加一层轻微的外发光让它们突出）

═══════════════════════════════════════
整体风格约束
═══════════════════════════════════════

- 柔和：不要有硬边、锐角、强烈对比
- 清新：颜色以浅蓝、白、淡黄为主，不超过 4 种主色
- 通透：白色和浅色之间要有透明感，不要像油漆一样厚重
- 简洁：不要渐变光效、不要立体阴影、不要金属质感
- 和 App 的 UI 风格一致（浅色、圆角、轻量）

═══════════════════════════════════════
输出要求
═══════════════════════════════════════

1. 直接覆写 /root/workspace/notes-app/tasks/icon/icon-c.svg
2. 先备份旧版：cp icon-c.svg icon-c-old.svg
3. 输出纯 SVG，不要外部字体、不要外部图片、不要 JavaScript
4. 所有颜色和渐变都内联在 SVG 里
5. 告诉我文件路径和大小
6. 不要动 index.html 或任何其他文件
