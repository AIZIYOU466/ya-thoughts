问题 1：主题切换闪帧——真正根因是覆盖层消失和 data-theme 应用不在同一渲染帧
═══════════════════════════════════════

当前现象：圆形扩散覆盖全屏，覆盖完成时闪一下，像是页面被重新加载。

根因分析（按 motion-web 的 "no flash" 规则）：
- 覆盖层盖满屏幕时，下面还是旧主题的 DOM
- 覆盖层被移除的瞬间，页面"露出"旧主题，然后才被浏览器渲染成新主题
- 中间的 1-2 帧就是用户看到的闪屏

正确修复：
1. 覆盖层保持纯色 var(--bg-page)，不透明，不要有任何 box-shadow、border。
2. 圆形铺满屏幕的那一帧，执行以下顺序：
   a. 先给 <html> 设置 data-theme = 新主题
   b. 强制浏览器重排一次：void document.documentElement.offsetHeight
   c. 然后在下一帧的 requestAnimationFrame 回调里再移除覆盖层
3. 用双 rAF 包裹：
   requestAnimationFrame(() => {
     document.documentElement.setAttribute('data-theme', newTheme);
     void document.documentElement.offsetHeight;
     requestAnimationFrame(() => {
       overlay.remove();
     });
   });
4. 覆盖层移除时不要有 transition，直接 remove()。
5. 覆盖层和页面背景色必须严格一致（都用同一个 CSS 变量的值）。

问题 2：卡片删除动画改成"均匀速率"
═══════════════════════════════════════

用户反馈：当前 ease-in-expo 太"头重脚轻"（前半段几乎不动，后半段突然加速），要改成均匀速率。

修改：
1. 缓动从 ease-in-expo 改为 linear：p = t
2. 位置、scale、opacity 都走同一个 linear 曲线。
3. 时长保持 550ms。
4. scale 从 1 到 0.05 线性变化。
5. opacity：前 60% 保持 1，后 40% 线性衰减到 0：
   opacity = t < 0.6 ? 1 : (1 - (t - 0.6) / 0.4)
6. transform-origin 保持 right top。

问题 3：长按菜单的"删除"也要触发曲线动画
═══════════════════════════════════════

当前：长按卡片弹出菜单（置顶/复制/删除），点"删除"后直接删，没有动画。
要求：点"删除"后，卡片从原位飞向右上角垃圾桶，同时缩小消失，动画结束后真实删除数据。

修改：
1. 找到长按菜单里"删除"按钮的点击处理函数。
2. 在函数开头，先获取当前卡片的 boundingRect。
3. 调用已有的 flyToTrash(cardElement, boundingRect) 动画函数（复用曲线删除的动画逻辑）。
4. 数据删除（从 IndexedDB 移除 note 和 images）等动画结束的回调里执行。
5. 动画期间禁用菜单，防止重复点击。
6. 如果动画被打断或抛出异常，也要执行一次数据删除，避免数据不一致。
