现象 2：长按拖拽完全不跟手
═══════════════════════════════════════

在真机 APK 上：
- 长按 500ms，卡片有放大和阴影（说明进入拖拽状态了）
- 但手指上下移动，卡片纹丝不动
- 松手后卡片回到原位

要求：按 systematic-debugging 流程：
1. 读 index.html，定位手势入口的 pointerdown、pointermove、pointerup 处理函数。
2. 明确回答：
   a. pointermove 监听是挂在卡片元素上，还是挂在 window/document 上？
   b. pointerdown 时是否调用了 setPointerCapture？如果没有，为什么？
   c. .note-item 当前的 CSS touch-action 是什么值？
   d. 进入拖拽状态时，touch-action 是否被动态改成 none？
   e. pointermove 里是否调用了 e.preventDefault()？监听器是否 passive: false？
3. 用一句话说清：为什么移动时卡片不跟手。
4. 然后才提出修复。

修复要求（必须全部做到）：
- pointerdown 第一行就调用 el.setPointerCapture(e.pointerId)
- pointerdown 时同时给卡片加 .gesturing 类；CSS 里 .gesturing { touch-action: none !important; }
- pointermove 监听注册在 window 上：pointerdown 时 addEventListener('pointermove', onMove, { passive: false })，pointerup 时 removeEventListener
- onMove 第一行 e.preventDefault()
- 位移计算：dy = e.clientY - startY（不要用 e.movementY）
- 卡片位置：transform: translate3d(0, dy, 0)
- 其他卡片让位：按当前 dy 计算应插入的索引，用 translate3d 让它们上下移动
- pointerup：判断最终索引，写入 IndexedDB 的 order 字段，清除 .gesturing 和 inline transform
