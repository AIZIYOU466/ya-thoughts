决策 1：CURRENT_VERSION
═══════════════
本次打包会把 versionName 升到 1.6.0（因为加了图片裁剪这个新功能）。
所以 CURRENT_VERSION 用 '1.6.0'，和 versionName、version.json 三者一致。

测试"有更新"场景的方法：
- 装好 APK 后，手动在 GitHub 上把 version.json 里的 version 改成 '9.9.9'
- 重新打开 App → 2 秒后弹出"发现新版本 v9.9.9"
- 测完删掉或改回真实版本

═══════════════
backButton 判断（重要）
═══════════════
同意在 backButton 监听器最前面加一个判断：
if (更新弹窗已打开) { 关闭弹窗; return; }

这是必要的——否则用户打开更新弹窗后按系统返回键，会直接返回列表页，
体验很怪。这个插入是最小侵入，只加一个 if 分支，不改现有逻辑。
