二、改 .github/workflows/build-apk.yml
═══════════════════════
1. 文件顶部加：
   permissions:
     contents: write

2. Build APK 之后加三步：

- name: Extract version
  id: get_version
  run: |
    VERSION=$(grep -oP 'versionName "\K[^"]+' android/app/build.gradle)
    echo "version=$VERSION" >> $GITHUB_OUTPUT

- name: Generate version.json
  run: |
    V="${{ steps.get_version.outputs.version }}"
    R="AIZIYOU466/ya-thoughts"
    cat > version.json << EOF
    {
      "version": "$V",
      "notes": "自动构建 $V",
      "apkUrl": "https://gh-proxy.com/https://github.com/$R/releases/download/v$V/app-release.apk",
      "apkUrlBackup": "https://ghfast.top/https://github.com/$R/releases/download/v$V/app-release.apk"
    }
    EOF

- name: Commit version.json
  run: |
    git config user.name "github-actions[bot]"
    git config user.email "github-actions[bot]@users.noreply.github.com"
    git add version.json
    git commit -m "chore: update version.json [skip ci]" || echo "no changes"
    git push

3. 再加一步创建 Release：
- name: Create Release
  uses: softprops/action-gh-release@v2
  with:
    tag_name: v${{ steps.get_version.outputs.version }}
    name: Ya thoughts v${{ steps.get_version.outputs.version }}
    files: android/app/build/outputs/apk/release/app-release.apk
    make_latest: true
  env:
    GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}

⚠️ 死循环避免：commit message 必须带 [skip ci]。
⚠️ 同 tag 重复推送会失败，所以每次必须改 versionName。

三、App 内逻辑（index.html）
═══════════════════════
常量：
const CURRENT_VERSION = '1.6.0';
const URLS = [
  'https://cdn.jsdelivr.net/gh/AIZIYOU466/ya-thoughts@main/version.json',
  'https://gh-proxy.com/https://raw.githubusercontent.com/AIZIYOU466/ya-thoughts/main/version.json',
  'https://ghfast.top/https://raw.githubusercontent.com/AIZIYOU466/ya-thoughts/main/version.json'
];

compareVersion(a, b)：按 '.' 分割逐位数字比较，返回 1/-1/0。

checkForUpdate()：
1. 依次 fetch 每个 URL，5 秒超时，第一个成功就 break。
2. 全部失败 → 静默 return。
3. compareVersion(CURRENT_VERSION, info.version) >= 0 → return。
4. 检查 localStorage: update_dismissed_version 和 update_dismissed_at，
   同版本且 <24h → return。
5. showUpdateDialog(info)。

启动时：setTimeout(checkForUpdate, 2000)。

只在 window.Capacitor 存在时执行。
