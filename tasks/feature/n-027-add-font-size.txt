任务目标
═══════════════════════════════════════

在编辑页底部的功能工具栏（B / A / 图片）里，新增一个"字体大小"胶囊按钮。

用户场景：
- 用户在编辑页里选中一段文字。
- 点击底部的"字号"胶囊。
- 弹出一个小面板，显示几档预设字号（小 / 正常 / 大 / 特大）。
- 点某一档 → 选中的文字应用该字号。
- 再点同一档 → 取消（恢复正常）。

═══════════════════════════════════════
视觉设计
═══════════════════════════════════════

【胶囊按钮】
- 和现有的"图片"胶囊视觉完全一致：相同的高度、内边距、圆角、
  背景色（浅灰 #F0F2F5）、文字 14px/500、图标 16px。
- 图标：用两个大小不同的"A"字（比如大写 A + 小写 a），或者用
  一个带上下箭头的 T，表示"字号调整"。推荐用 SVG 图标，
  不要用 emoji。
- 文字：显示"字号"两个字。

【弹出面板】
- 点击胶囊后，在胶囊上方弹出一个小面板。
- 面板样式与液态玻璃一致：背景 var(--glass-bg-strong)，
  backdrop-filter: var(--glass-blur)，圆角 14px，阴影。
- 面板内横向排列 4 个选项按钮：
  · "小"（对应 14px）
  · "正常"（对应 16px，默认）
  · "大"（对应 19px）
  · "特大"（对应 23px）
- 每个选项按钮显示该档位的文字预览（用对应字号渲染"字号"两个字）。
- 选中的档位高亮（背景变主色 #2E6BE6，文字变白）。
- 面板宽度自适应，不要超过屏幕宽度减去 32px。

【弹出动画】
- 面板从下往上淡入（translateY(8px) → 0，opacity 0 → 1），200ms。
- 点击面板外部或再次点胶囊关闭。

═══════════════════════════════════════
技术实现
═══════════════════════════════════════

【CSS 类定义】
定义 4 个字号类，应用到文本上：
.fs-small { font-size: 14px; }
.fs-normal { font-size: 16px; }  /* 默认，可不加类 */
.fs-large { font-size: 19px; }
.fs-xlarge { font-size: 23px; }

【应用到选中文字】
- 用户选中一段文字，点"小" → 把选中的文字包进
  <span class="fs-small">...</span>
- 再点"正常" → 移除字号类，恢复默认。
- 用 document.execCommand 的 fontSize + 后处理，或者用 Range
  包裹方式实现。

推荐用 Range 包裹方式（更可控）：
1. 获取当前选区 getSelection().getRangeAt(0)
2. 检查选区是否已经被 span.fs-* 包裹
   · 如果是 → 移除那个 span 的类，或替换类名
   · 如果否 → 用 range.surroundContents 包一个新 span
3. 保留原有的加粗、高亮等标签（不要破坏嵌套）

【撤销/重做兼容】
- 应用字号后，触发一次 undo 快照（调用现有的 pushUndoSnapshot 或等价逻辑）。
- 撤销时能恢复到应用前的状态。

【数据持久化】
- 字号通过 <span class="fs-xxx"> 存在 HTML 内容里，
  自动被现有的 innerHTML 序列化保存到 IndexedDB。
- 读取时直接 innerHTML 还原，样式自动生效。
- 导出/导入 JSON 时，HTML 里包含的 span 标签会一起保存和还原。

【浏览器兼容】
- 所有操作用标准 Range / Selection API，兼容 Android WebView。
- 如果 getSelection() 返回空（无选区），点击胶囊时提示"请先选中文字"，
  或者直接弹出面板让用户先选。

═══════════════════════════════════════
交互细节
═══════════════════════════════════════

1. 用户没有选中任何文字就点"字号"胶囊：
   - 选项显示为灰色不可点。
   - 或者点击时 toast 提示"请先选中文字"。

2. 用户选中的文字已经是某个字号：
   - 弹出面板时，对应的档位显示为选中状态。

3. 用户点了不同的档位：
   - 直接替换，不需要先取消。

4. 面板打开时，用户改了选区（比如重新选了别的文字）：
   - 面板自动关闭，或者保持打开但应用目标更新为新选区。
   - 推荐：面板保持打开，点击档位时应用当前选区。

5. 点击面板外任意地方：
   - 关闭面板。

- 不改布局宽度。
- 保留液态玻璃视觉效果。

  不加新的 note 字段）。
- 不改导出/导入逻辑（HTML 内容自动包含 span 标签）。
- 胶囊按钮和现有 B / A / 图片胶囊视觉完全一致。
